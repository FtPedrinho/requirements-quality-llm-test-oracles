# Documentação original

`tool-readme-original.md` é uma cópia byte a byte da fonte normativa registrada no manifesto. `technical-specification.pdf` é preservado como referência de arquitetura/proposta e não deve servir para criar expectativas que o README não especifica como comportamento atual.

Os caminhos relativos que aparecem dentro do README foram preservados sem edição para manter a cópia e o hash originais. Eles são relativos à raiz do repositório, não a esta pasta. Os relatórios referenciados são artefatos do produto, não resultados desta pesquisa.

Veja [manifest.json](manifest.json) para origem e hashes.
