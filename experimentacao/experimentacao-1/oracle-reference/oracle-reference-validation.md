# Validação do gabarito independente

O catálogo independente contém comportamentos da ferramenta MC/DC confirmados por:

- implementação Java;
- CLI real;
- testes JUnit existentes;
- execução realizada nesta sessão;
- documentação README/USAGE.

O catálogo não usa os oráculos antigos de VM/TIS/NPP como referência.

Os itens não executados ou sem evidência suficiente serão mantidos como não avaliáveis.
