# Histórico das alterações da documentação EXP1

## Documentos duplicados

- README original da ferramenta;
- especificação técnica PDF;
- nova versão C1 em Markdown.

## Alterações

- estrutura por finalidade;
- explicação do SUT;
- separação entre Z3 opcional e implementação;
- padronização dos nomes dos comandos;
- descrição dos formatos de saída;
- registro dos limites numéricos implementados;
- registro dos códigos de saída;
- exclusão de afirmações não confirmadas pelo código.

## Sem alteração funcional

Não foram criadas funcionalidades novas. Todos os comportamentos foram preservados ou explicitados a partir do código atual.
