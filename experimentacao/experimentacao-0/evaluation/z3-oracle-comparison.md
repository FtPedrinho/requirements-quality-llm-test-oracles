# Comparação dos oráculos com as formalizações

## Resultado preliminar

Os 36 oráculos conservam a expressão ou o texto da decisão original como condição documentada.

| Classificação | Quantidade |
|---|---:|
| Compatível com a formalização | 36 |
| Incompatível | 0 |
| Parcialmente verificável | 0 |
| Não formalizável | 0 |
| Indeterminado | 0 |

Essa contagem representa correspondência estrutural inicial, não validação semântica independente.

## Limitações da comparação

- A geração dos oráculos precedeu a comparação formal apenas no registro da sequência, mas os artefatos não incorporaram resultados Z3 como respostas esperadas.
- A compatibilidade confirma que o oráculo inclui a guarda registrada.
- Não demonstra que o oráculo descreve corretamente estados anteriores, ações fora da guarda ou saídas não documentadas.
- Os casos concretos dependem de valores de domínio que não foram validados por implementação.
- Os conflitos TIS e NPP precisam ser avaliados antes de concluir compatibilidade real.
