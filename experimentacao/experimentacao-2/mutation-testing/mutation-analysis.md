# Mutation Testing C2

Este resumo histórico foi substituído pela execução primária PIT `mcdc-core` de 456 mutantes por cenário. Use [`mutation-summary.md`](./mutation-summary.md) e os três `mutation-results-*.csv` para os resultados finais S1/S2/S3.

O arquivo legado [`mutations.xml`](./mutations.xml) é de uma execução anterior, com escopo/população diferentes, e não deve ser combinado com os resultados atuais nem usado para calcular as métricas finais.
