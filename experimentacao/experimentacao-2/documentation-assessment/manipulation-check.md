# Verificação da manipulação

A clareza foi reduzida por:

- construção sintática indireta;
- termos menos específicos em descrições auxiliares;
- referências contextuais;
- organização menos direta.

A consistência foi preservada porque:

- limites não mudaram;
- fontes não mudaram;
- comandos não mudaram;
- códigos não mudaram;
- variantes não mudaram;
- formatos não mudaram;
- nenhuma contradição foi introduzida.
