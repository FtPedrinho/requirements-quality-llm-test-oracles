# Evidências complementares do Copilot

Este diretório contém as [evidências originais do C0 oficial](experimentos/C0/reinicio-2026-11-21/)
e o [prompt v2 utilizado](prompts/geracao-de-oraculos-v2.md), referenciados no
[relatório C0](../copilot-resultados/C0/C0-copilot.md). Não são entradas para
novas gerações de oráculos.

Os caminhos internos dos manifestos e executores refletem a localização
original. Uma reprodução pode exigir um workspace separado com a estrutura
original; não sobrescreva as evidências. O conjunto adotado e suas limitações
estão nos [resultados do Copilot](../copilot-resultados/).
