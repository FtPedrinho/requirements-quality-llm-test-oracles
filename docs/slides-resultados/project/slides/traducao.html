“A ferramenta não lê a frase em inglês; quem faz isso é a NAT2TEST, ao gerar o DFRS. Para estes testes eu traduzi à mão, com poucas regras: ‘is’ é o valor atual, ‘was’ é o valor no passo anterior, e ‘changes to’ é um evento: antes não era, agora é. O que vem depois de ‘shall’ são as ações, que não entram no cálculo do MC/DC.” O REQ001 chegou cortado (“dle, and the coin sensor…”); foi considerado “When the system mode is idle”.
