“A mesma análise sai em três arquivos. O JSON é o mais completo, com a tabela, os pares e os testes, e é o que vai para o visualizador da NAT2TEST. O CSV dos testes traz só os 26 testes escolhidos, bom para quem vai executá-los. E o CSV da tabela, que é novo, traz as 152 linhas, uma coluna por condição, dizendo se a linha é possível e se virou teste. Na faixa escura, um pedaço dele: a linha V4 do REQ004 aparece com feasible F, ou seja, impossível.” O cabeçalho mostrado na faixa está abreviado; no arquivo, as colunas têm os nomes completos das condições.
