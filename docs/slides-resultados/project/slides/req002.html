Cada um dos outros tira exatamente uma condição, e a máquina não reage. É a regra da porta and: um teste com tudo verdadeiro e um para cada condição sozinha em falso.” Valores do Z3: no V1, modo = choice, moeda = false, moeda antes = false, botão antes = released, botão = pressed, timer = 0; no V2, o timer vai para 31.
